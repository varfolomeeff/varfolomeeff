### 🔬 Research, Publications & Open-Source

* **Dynamic Codebook Adaptation (AIRI Research):** Authored a novel method for dynamic codebook size adaptation in VQ-VAEs via a Codebook Size Predictor (CSP) module with Truncated-GMM sampling. When integrated with an audio-tokenized LM (Qwen2.5 0.5B), it significantly boosted UTMOS metrics from ~1.5 to ~2.0 while achieving 99% codebook utilization.
* **The ESpeech Ecosystem:** Co-authored and scaled the *ESpeech* data pipeline, establishing a new SOTA baseline for Russian speech synthesis. A comprehensive architectural overview is documented in **ESpeech-techreport.pdf**.
  * *ESpeech:* Developed an automated processing pipeline transforming 50,000 hours of raw audio into 12,801 hours of ultra-clean multi-speaker TTS data.
  * *ESpeech-2:* Scaled the ingestion pipeline to process **1,000,000 hours** of raw acoustic data, delivering a 200,000-hour corpus optimized for high-fidelity dubbing and on-device emotional TTS.
* **Audio2MIDI (Automated Piano Transcription):** Architected a comprehensive 4-stage pipeline translating multi-instrumental audio directly into structured piano arrangements. Built the industry's largest paired audio-arrangement dataset leveraging a custom Dynamic Time Warping (DTW) alignment pipeline.
